איפה מקבלים כל מפתח? (מדריך מהיר)

🤖 שירות (Gemini) — aistudio.google.com → בחרו פרויקט → Create API key (חינם). מדגם: AIza...

📧 SMTP — נפוצים: Gmail (myaccount.google.com → אבטחה → App passwords, יש צורך ב-2FA), Brevo (free 300 מיילים/יום), Resend, SendGrid.

📸 אינסטגרם — developers.facebook.com → אפליקציה → Instagram API → לכאלה עם חשבון עסקי; טוקן ארוך-טווח מ-Graph API Explorer.

🛫 AliExpress — portals.aliexpress.com → Affiliate Program (אישור 1–3 ימים) → AliOpen → Create App → App Key/Secret + Tracking ID.

📦 eBay — developer.ebay.com (App ID + Cert ID, חינם מיידי) + epn.ebay.com ל-Campaign ID של עמלות.

🛒 Amazon — affiliate-program.amazon.com → Partner Tag מיד; PA-API Keys אחרי 3 מכירות/180 יום (اپسilon.amazon.com / PA-API v5).

🌐 Awin / CJ — awin.com / cj.com → הצטרפות → API token מהדשבורד (Awin: Settings → API credentials; CJ: API v3 → Bearer token).

🛍️ Rakuten Advertising — rakutenadvertising.com / developers.rakutenadvertising.com → Developer Portal → API Credentials (Client ID + Secret) + Site ID (Account ID). הרשת של Etsy ומותגים גדולים.

🔑 Google OAuth (התחברות עם Google) — console.cloud.google.com → Credentials → OAuth Client ID (Web) → Client ID + Secret. הוסיפו ב"Authorized redirect URIs" את {{ site_url or 'https://האתר-שלך' }}/auth/google/callback

📦 Temu — תוכנית שותפים (temu.com → affiliate) → Affiliate ID; אין API ציבורי — האתר משתמש בו לפרמטר מעקב בלבד.

🚚 17TRACK — 17track.net → API Key (למעקב משלוחים). ✈️ טלגרם — @BotFather → /newbot → Bot Token, ו-Chat ID מ-@userinfobot.

📄 המדריך המלא והמפורט (צעד-צעד עם צילומי מסך) שמור בפרויקט בקובץ SUPPLIERS_GUIDE.md.

✈️ התראות טלגרם

🔑 התחברות עם Google (OAuth)

בלי המפתחות, כפתור "המשך עם Google" בעמודי ההרשמה/התחברות מציג הודעה "עדיין לא הופעל".

💬 WhatsApp — התראות ועדכונים

WhatsApp Business API — developers.facebook.com → אפליקציה → WhatsApp → Setup. ה-Phone Number ID מתקבל מלוח הבקרה של WhatsApp.

🔔 Web Push — התראות דפדפן (VAPID)

הפקת מפתחות: pip install pywebpush && pywebpush gen-keypair. ה-public key נדרש במניפסט ובצד הלקוח; ה-private key בשרת.

🌐 כללי ואבטחה

פניות ממרכז העזרה (טופס "כתבו לנו") נשמרות באתר ונשלחות במייל לכל הכתובות פה — וגם ל-ADMIN_EMAIL. אפשר לצפות בהן בלוח הבקרה → פניות.

הערה: שינוי של ADMIN_SECRET_KEY מתבטא בכניסה הבאה ללוח הניהול.

💡 שדה ריק = שומרים את הערך הקיים (לניקוי סודות יש תיבת "מחק"). כפתור "בדוק חיבור" בודק את הערכים שהוקלדו בטופס (ואם ריק — את הערכים השמורים). באחסון מאונדכס (למשל Render) שמירה משנה את ההגדרות לסשן הנוכחי — יש לשכפל אותן גם בדשבורד של ספק האחסון כדי שיישמרו בין redeploy.
